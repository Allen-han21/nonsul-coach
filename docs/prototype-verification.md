## 실제 연결 전 필수 확인

비공개 배포 검증: [논술코치](https://nonsul-coach-sungshin.dongwookq.chatgpt.site). 배포 성공 및 소유자 전용 접근을 확인했다. 비인증 HTTP 요청은 401, 인증된 홈과 원본 그림은 200이다. 공유 이미지 메타데이터가 실제 배포 원점을 가리키며, 합성 답안 요청은 AI 미설정으로 503/NOT_CONFIGURED와 no-store 응답을 반환했다. 외부 AI 호출이나 실제 분석 성공은 포함하지 않는다.

1. 분석 제공자·모델과 자격 증명을 확정한다. `web/.env.example`에 필요한 설정 이름만 있다. 키는 Git·채팅·브라우저에 넣지 않는다.
2. 선택한 제공자 프로젝트와 모델의 **요청·응답 본문 비보관 조건**을 운영자가 확인한다. `ANALYSIS_RETENTION_CONFIRMED=true`는 운영자 확인값이지 제공자 설정을 바꾸거나 비저장을 기술적으로 증명하는 기능이 아니다.
3. OpenAI를 선택할 경우 현재 준비된 Responses API 어댑터를 사용할 수 있다. `store:false`, 비백그라운드 요청, 대화 ID·파일·도구·자동 재시도 미사용이다. `store:false`만으로 남용 감시 로그의 보관이 없어지지는 않는다. 승인된 데이터 보관 제어와 선택 모델의 적용 여부를 별도로 확인해야 한다. [OpenAI 데이터 제어 공식 문서](https://developers.openai.com/api/docs/guides/your-data).
4. 구조화 응답은 형식을 제한할 뿐 판단의 정확성을 보장하지 않는다. 실제 모델로 여섯 문항의 정상·누락·반론·오류 입력과 수정 답안을 검토해야 한다. [OpenAI 구조화 응답 공식 문서](https://developers.openai.com/api/docs/guides/structured-outputs).
5. OpenAI 키 관리 스킬이 현재 제공되지 않아 키를 생성하지 않았다. OpenAI 연결이 선택되면 OpenAI Developers 플러그인의 키 관리 흐름 또는 사용자가 준비한 안전한 서버 설정이 필요하다.
6. Sites 배포용 소스 커밋·푸시는 사용자 승인 후 완료했다. 후속 배포는 기존 프로젝트와 Sites 전용 저장소를 재사용한다. 상위 GitHub 저장소를 임의로 푸시하지 않는다.
7. 배포 시 실제 신뢰할 수 있는 `SITE_ORIGIN`을 설정하고 공유 이미지 URL을 다시 확인한다. 현재 기본 URL은 로컬 미리보기용이다. 소유자 제한 접근과 호스팅의 본문 로그 비수집 여부도 확인한 뒤 실제 요청→피드백→수정→재분석을 검증한다.

## 교사 검토 절차

합성 또는 적절히 비식별화한 검토용 답안을 사용한다. 학생 신원 정보를 넣지 않는다.

1. 여섯 문항에서 판단 하나씩을 골라 공식 페이지의 기준과 연결이 맞는지 확인한다.
2. 답안 근거 선택 버튼으로 인용 범위를 확인한다. 누락 지적은 답안 전체와 바꿔 쓴 표현을 검토한다.
3. 질문이 학생의 사고를 유도하는지, 행동이 실제 수정 위치와 목표를 알려 주는지 검토한다.
4. 2026 1교시 문제 1의 다양한 운영 방안, 문제 2의 비필수 역진성 논의, 모의논술의 다양한 종합·대안 허용을 확인한다. 2교시는 심리적 역설의 적용과 두 정의관·기업윤리의 연결을 각각 검토하고, 원문에 없는 외부 사례를 강요하지 않는지 확인한다.
5. 수정 답안에 대해 같은 기준이 적용되고, 개선되지 않은 부분을 개선되었다고 단정하지 않는지 확인한다.

교사 판정·의견은 아직 받지 않았다. 이 문서에 학생 답안이나 식별정보를 붙이지 않는다.

## 알려진 한계

- 실제 모델의 의미 판단·문항 일치 판정은 미검증이다. 2차 검토도 AI이므로 두 판단이 함께 틀릴 가능성이 있다.
- 설명·질문은 검토된 기준별 문구를 사용한다. 개인화는 판단 종류와 근거 위치 수준이며, 자유로운 문장 대필을 하지 않는다.
- 글자 수는 참고값이다. 공백 처리에 따라 판정이 달라지면 ‘확인 필요’로 둔다.
- 개인정보 정규식은 이메일·전화번호·주민등록번호 모양만 차단한다. 모든 이름·학교명·식별정보를 탐지한다는 보장은 하지 않는다.
- 브라우저의 메모리에만 입력과 현재 결과가 있다. 새로고침 시 없어지며 복구·저장 기능은 의도적으로 없다.
- 비공개 배포 URL은 있으나 AI 설정은 미완료다. 실제 AI 첨삭이 활성화되었다거나 교사 검증을 받았다고 안내하면 안 된다.
